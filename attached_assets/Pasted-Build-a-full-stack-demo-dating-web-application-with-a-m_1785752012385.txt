Build a full-stack demo dating web application with a modern UI inspired by Bumble and Hinge (do not copy their branding, logos, or exact design). The app is for demo/testing purposes only.

Tech Stack
Frontend: React + Vite + Tailwind CSS
Backend: Node.js + Express
Database: SQLite (or PostgreSQL if easier on Replit)
Authentication: Demo authentication only (no real Google or Instagram OAuth)
Features
1. Login Page

Create a beautiful modern login page with:

App logo at the top
Clean gradient background
Two login buttons:
Login with Gmail
Login with Instagram
Below the buttons, show demo credentials that users can use for testing.
Since this is a demo app, do not implement real Google or Instagram login. Instead, simulate these login methods by validating against demo accounts stored in the database.
